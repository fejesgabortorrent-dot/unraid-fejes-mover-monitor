# FejesNAS Mover Monitor — Universal

Mover activity dashboard and file monitor for Unraid 7+, with a Hungarian interface.

## Status

**Development preview — not yet approved by Community Applications.** This repository is being prepared for a portable, read-only release. Do not install the draft on a production NAS.

The planned universal edition provides a Tools status page and Dashboard tile, pool-capacity readings, Mover activity, and recent log excerpts. It does not require the FejesNAS-specific `Filmek_Mover_Threshold` User Scripts automation, and does not start or control Mover.

## Release checklist

- Review and publish portable PHP source files.
- Test on Unraid 7 with zero, one, and multiple pools.
- Verify output escaping, process detection, performance, and reboot persistence.
- Package a public, checksum-verified `.plg` installer and release archive.
- Test install, update, uninstall, and rollback on a test NAS.
- Confirm a license and add icon, support links, and Community Applications metadata.

**No license has yet been selected for the public release.**
