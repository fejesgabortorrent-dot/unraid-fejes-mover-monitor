# FejesMover interface concept

Download `index.html` and open it in a modern browser. No installation, server,
NAS connection or external assets are required. GitHub's file viewer displays
HTML source; download the file to interact with it locally.

- Hungarian, English and German, including scenario labels and history.
- Compact Dashboard card with a details button, responsive pool card and clear protection states.
- Nine selectable synthetic scenarios and adjustable start threshold.
- Dry-check button records a decision in session-only history (maximum 50 rows).
- Light and dark themes; language and theme are remembered when browser storage
  is available. Local file storage behavior can vary by browser.
- The HTML view illustrates decisions. It does not execute Python, call an API,
  move files, write NAS settings or start Mover.

The 12/12 evidence link points to a checked-in example of the **separate** real
Python/Bash simulation. It is not a test result generated by clicking this UI.
Actual Unraid integration, pool selection and a separate stop threshold remain
future work. The fixed 360-minute retry interval describes the reviewed launcher.

Validation: `node tools/demo_test.cjs`. GitHub also runs real browser interactions
with Playwright and uploads desktop/light/mobile screenshots in the
`fejes-mover-interface-preview` artifact. These browser tests are separate from
the production helper and packaging checks.
